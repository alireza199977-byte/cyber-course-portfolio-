In this exercise, I first connected the network devices and computers according to the connection table. I used Copper Straight-Through cables to connect the devices and then turned them on.


Next, I set the Admin PC and Manager PC to DHCP so they could automatically receive an IP Address. I also configured the Printer with the static IP address 192.168.1.100 and the Subnet Mask 255.255.255.0.

Then, I checked the IP settings of the computers. I noticed that the two computers had different IP addresses, but their Subnet Mask and Default Gateway were the same. This is because both computers are on the same network, but each device needs to have a unique IP address.

To check the connectivity, I used the ping command, and the connection between the computers and the Printer was successful.

Next, I checked the connection to the Internet using the IP address 209.165.200.225. I also tested the connection using the server's URL. If the connection works with the IP address but not with the URL, the problem could be related to DNS.

Then, I used the ipconfig and ipconfig /all commands in the Command Prompt. The ipconfig /all command displayed additional information such as the MAC Address, DHCP Server, and DNS Server.

Finally, I used the tracert command to check the path to the server. The routers on the path were identified by their IP addresses. The second router, 209.165.200.233, was located on the ISP/Internet side of the network.

1. Why are the IPv4 addresses different, but the subnet masks and default gateways are the same?
Because each computer needs its own unique IP address, but they are on the same network, so they have the same subnet mask and default gateway.

2. If the printer needs a default gateway, which value will it use?
192.168.1.1
Because this is the router's address and the default gateway for the network.

It is probably a DNS problem because DNS changes the website name into an IP address.
