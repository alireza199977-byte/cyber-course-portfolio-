In this lab, I used Packet Tracer to see how a PC communicates with a server when opening a website.
First, I changed the mode to Simulation Mode and set the filters to show only DNS and HTTP. Then I opened the web browser on the PC and entered www.example.com.
The PC first sent a DNS request to find the IP address of the website. After receiving the IP address from the server, the PC sent an HTTP request to get the web page. The server then sent the web page back to the PC.
Finally, I checked the PDU Information to see the details of the packets and how the communication goes through the OSI layers.
